## 👋 About Me

I'm **Maksim**, a **QA Engineer and Web Developer** interested in both sides of software engineering — building products and understanding how they behave under real-world conditions.

As a QA Engineer, I work with **web applications, REST APIs, Android and iOS apps**. I investigate application behavior through browser DevTools, API requests, network traffic, logs, databases and proxy tools.

I pay particular attention to **edge cases, reproducibility, user flows and clear bug documentation**.

As a Web Developer, I work with **JavaScript / TypeScript, React, Next.js, Node.js and databases**, which helps me understand application architecture and communicate more effectively with developers.

> **I like understanding not only where something breaks, but why it breaks.**

## 🧪 QA Engineering

I work across **Web, API and Mobile QA**.

- Functional, exploratory, smoke and regression testing
- Web UI and end-to-end user flow testing
- Android and iOS application testing
- REST API testing with Postman
- HTTP / HTTPS request and response analysis
- JSON and API data validation
- Mobile network traffic inspection
- Proxy-based debugging with Proxyman
- Test cases, checklists and test scenarios
- Negative testing and edge-case discovery
- Boundary-value analysis
- Browser DevTools investigation
- Network and Console debugging
- SQL and backend data validation
- Clear and reproducible bug reports
- Playwright automation with JavaScript / TypeScript
